# Start here

You do **not** need to become a programmer.

You need to become a **clear manager of a powerful assistant**.

Cursor is that assistant. This kit turns it into your **daily driver** — the first place you go for writing, research, organizing files, trip/admin logistics, and repeatable computer chores.

## Who this is for

- Smart, busy, non-technical (or lightly technical)
- Want AI help for **personal work + web activity + automation**
- Prefer **copy-paste Recipes** and fill-in-the-blank **Variables** over jargon

## What “daily driver” means

Cursor is open most days. You have:

1. A **Personal Ops** folder (your home base)
2. A short list of **Recipes** you trust
3. **User Rules** that sound like you
4. A habit of **reviewing** before you accept changes
5. Optional **Cloud Agents** for jobs while you’re away

## The only mental model you need

**You = boss. Cursor = assistant.**

Good bosses give:

- **GOAL** — what success looks like  
- **CONTEXT** — background + files (`@`)  
- **CONSTRAINTS** — what not to do  
- **DONE-WHEN** — how you’ll know it’s finished  

Then they **review** the work.

## Safety in one line

Never paste passwords, one-time codes, full card/bank numbers, government IDs, or API keys into chat.
