# Carson Cursor — Comprehensive Plan

A 21-day recipe to make Cursor Carson’s **daily driver** and build real mastery without a tech background.

> Time budget: about **5–8 hours/week** (45–75 minutes most days).  
> Graduation artifact: `HOW_I_USE_CURSOR.md` inside your Personal Ops folder.

---

## Part 1 — Install day zero (30–45 minutes)

1. Download Cursor: https://cursor.com/download  
2. Sign in; pick a plan that supports the Agent features you need (see https://cursor.com/docs/models-and-pricing ).  
3. Create folder `Carson-Personal-Ops` with:

```text
Inbox/
Projects/
Recipes/
Wins/
Reference/
Templates/
Archive/
```

4. In Cursor: **File → Open Folder** → select that folder.  
5. Create `Reference/never-paste.md` and `Reference/voice-samples.md`.  
6. Ask mode: *“Explain this workspace like I’m not technical and suggest my first 3 files to create.”*

## Part 3 — Mode picker (print this)

| Mode | Plain English | Carson examples |
|---|---|---|
| **Ask** | Explain / compare / brainstorm without changing files | Confusing PDF; “what are my options?” |
| **Plan** | Design first; you approve | New filing system; family logistics board |
| **Agent** | Do the work with review | Create templates; draft email file; build CSV |
| **Debug** | Investigate with evidence | Personal page/script broke |

Default path: **Unclear → Ask → (Plan?) → Agent → Review**.

Official comparison: https://cursor.com/help/ai-features/agent

## Part 5 — Daily driver rituals

### Morning (15–25 min)

1. Open Personal Ops  
2. Ask: “Based on `@Projects` and `@Inbox`, what are today’s top 3?”  
3. Run **one** Agent Recipe  
4. Park the rest as notes (don’t open 10 chats)

### Midday (10 min)

Unstick one chore with a Recipe. Finish or write the next step.

### Shutdown (10–15 min)

Move wins → capture Recipe improvements → write tomorrow’s Top 3 → close Cursor.

This shutdown is what makes tomorrow easy.

## Part 6 — Personal OS blueprint (end state)

Your graduation README (`HOW_I_USE_CURSOR.md`) should include:

1. Folder map  
2. Rituals  
3. Top 8 Recipes (links)  
4. User Rules summary  
5. Never-Paste + human gates  
6. MCP plan (even if “none yet”)  
7. Cloud brief templates  
8. Official links + monthly changelog habit  
9. 30-day maintenance loop  

Core standing orders to consider:

- Explain jargon in plain English (parentheses OK)  
- Ask before deleting or moving originals  
- Do not invent facts; mark unknowns  
- Prefer Markdown in `Templates/` and `Projects/`  
- Default tone: warm, direct, no hype  
- Always state DONE-WHEN for deliverables

## Part 7 — Automation ladder (don’t skip rungs)

1. **Better prompts** (Variables + Recipes)  
2. **Folder conventions + templates**  
3. **User/project rules**  
4. **Skills / slash workflows**  
5. **MCP tool connections** (low-risk first)  
6. **Cloud Agents** for async jobs  
7. Only then: custom scripts/apps if you still need them  

Most of Carson’s wins live on rungs 1–4.

---

## Part 8 — Mastery definition (honest)

Carson is a **Cursor tool expert** when he can:

- Pick modes without hesitation  
- Brief with Variables in under 2 minutes  
- Run Recipes for writing, research, files, life ops  
- Maintain rules/skills without bloat  
- Kick off a self-contained cloud brief  
- Teach a friend the system in 10 minutes  
- Review AI output like a manager, not a spectator  

Not required: writing compilers, memorizing every shortcut, or connecting every integration on day one.

---

## Part 9 — Keep sharp (after day 21)

**Weekly:** prune one Recipe · add one Win · shorten/delete one unused rule  

**Monthly:** skim https://cursor.com/changelog · revisit MCP · practice one advanced pattern from https://cursor.com/blog/agent-best-practices  

**When stuck:** new chat + `@Past Chats` + tighter DONE-WHEN — don’t thrash in a confused thread.
