# Glossary

| Term | Definition |
|------|------------|
| **Accrual** | Record expense/revenue in the period earned/incurred before cash or invoice |
| **Aging** | Open AR/AP buckets by days outstanding |
| **ASC 606** | US GAAP revenue recognition standard |
| **Control account** | GL account that must equal its subledger |
| **Deferred revenue** | Liability for cash/billing before performance |
| **DSO / DPO** | Days sales / payable outstanding |
| **GRNI** | Goods received not invoiced |
| **Journal entry (JE)** | Debit/credit posting to the GL |
| **Natural account** | CoA account for the economic “what” |
| **Prepaid** | Asset for payment before expense period |
| **Reclass** | Move amount between accounts without changing equity |
| **Subledger** | Detailed module (AR, AP, FA) that posts to GL |
| **Trial balance (TB)** | List of all GL accounts with debit/credit balances |
| **Unbilled AR** | Contract asset — revenue recognized before billing |
| **Waterfall** | Schedule showing beginning balance, adds, releases, ending balance |
| **Working capital** | Current assets − current liabilities (AR, AP, deferred interplay) |
