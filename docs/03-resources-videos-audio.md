## Tier 3 — Video

|---|---|---|
| Cursor YouTube (official) | https://www.youtube.com/@cursor_ai | Watch recent feature demos at 1x in Week 1 |

| Search: Rules / Skills / MCP | https://www.youtube.com/results?search_query=Cursor+AI+rules+skills+MCP+tutorial | Visual setup walkthroughs for Week 3 |

**Video hygiene for laymen**

1. Check the upload date.  
2. Pause and recreate the click path in your own Cursor.  
3. If the UI differs, trust https://cursor.com/docs over the video.  
4. Take notes as a Recipe or User Rule — don’t binge passively.

---

## Tier 4 — Audio / listen-mode

Cursor doesn’t require a separate podcast to learn. For commute/walk learning:

1. Open a long official page (best practices or Cloud Agents).  
2. Use your browser **Reader** view.  
3. Use **Speak / Read aloud** (Safari, Edge, Chrome extensions, or OS narration).  
4. After listening, open Cursor and run one tiny practice (Mode Gym or one Recipe).

Suggested listen order:

1. https://cursor.com/blog/agent-best-practices  
2. https://cursor.com/docs/cloud-agent  
3. https://cursor.com/learn/customizing-agents
