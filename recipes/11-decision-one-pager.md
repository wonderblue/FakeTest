# Decision One-Pager

**Slug:** `decision-one-pager`  
**Category:** writing  
**Level:** starter

## When to use
Buy vs wait; hire vs DIY; school choice framing.

## Variables
`{{GOAL}}`, `{{CONTEXT}}`, `{{TONE}}`, `{{UNKNOWN_POLICY}}`, `{{OUTPUT_PATH}}`

## Prompt
```
MODE: Ask then Agent
GOAL: {{GOAL}}
CONTEXT: {{CONTEXT}}
OPTIONS: include in context
FORMAT: One page — Context / Options / Criteria / Recommendation / Risks / Decide-by date
TONE: {{TONE}}
UNKNOWN_POLICY: {{UNKNOWN_POLICY}}
OUTPUT_PATH: {{OUTPUT_PATH}}
```

## Done when
A partner could read it and discuss calmly.

## Safety
Separate facts from preferences explicitly.
