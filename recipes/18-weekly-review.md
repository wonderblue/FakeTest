# Weekly Review Ritual

**Slug:** `weekly-review`  
**Category:** habits  
**Level:** starter

## When to use
End of week reflection + next week setup.

## Variables
`{{DATES}}`

## Prompt
```
MODE: Agent
GOAL: Run weekly review using my folders
FILES: @Wins @Projects @Inbox
FORMAT:
1) Wins this week
2) Stuck / waiting-on
3) Lessons → new Recipe or Rule?
4) Next week Top 7
OUTPUT_PATH: Projects/weekly/{{DATES}}.md
TONE: Encouraging but honest
```

## Done when
Next week's Top 7 exists and Inbox is lighter.

## Safety
Don't turn review into self-attack.
