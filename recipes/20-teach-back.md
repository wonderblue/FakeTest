# Teach-Back Check

**Slug:** `teach-back`  
**Category:** learning  
**Level:** starter

## When to use
Before you trust you learned something.

## Variables
`{{GOAL}}`

## Prompt
```
MODE: Ask
GOAL: Quiz me on {{GOAL}} like a patient coach
AUDIENCE: non-technical
FORMAT: 5 questions; wait for my answers; then grade kindly with corrections
SUCCESS_CRITERIA: I can teach this to a friend
```

## Done when
You can explain it without reading notes.

## Safety
None special.
