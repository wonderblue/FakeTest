# Draft an Email in My Voice

**Slug:** `draft-email`  
**Category:** writing  
**Level:** starter

## When to use
Any email you dread writing.

## Variables
`{{GOAL}}`, `{{AUDIENCE}}`, `{{TONE}}`, `{{LENGTH}}`, `{{CONTEXT}}`, `{{EXAMPLES}}`, `{{CONSTRAINTS}}`, `{{REVIEW_GATE}}`, `{{OUTPUT_PATH}}`

## Prompt
```
MODE: Agent (or Ask for draft-only)
GOAL: {{GOAL}}
AUDIENCE: {{AUDIENCE}}
TONE: {{TONE}}
LENGTH: {{LENGTH}}
CONTEXT: {{CONTEXT}}
EXAMPLES: {{EXAMPLES}}
CONSTRAINTS: {{CONSTRAINTS}}
REVIEW_GATE: {{REVIEW_GATE}}
OUTPUT_PATH: {{OUTPUT_PATH}}
Produce: subject line options (3) + body draft + a shorter alternate.
Do not send anything — draft files only.
```

## Done when
You can paste into your mail app after one edit.

## Safety
Never include passwords; double-check promised dates.
