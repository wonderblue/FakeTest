# Decision Research Brief

**Slug:** `research-brief`  
**Category:** web  
**Level:** starter

## When to use
Choosing between options; learning enough to decide.

## Variables
`{{GOAL}}`, `{{DOMAIN}}`, `{{AUDIENCE}}`, `{{DATES}}`, `{{BUDGET}}`, `{{CONSTRAINTS}}`, `{{SUCCESS_CRITERIA}}`

## Prompt
```
MODE: Ask (use web tools if needed)
GOAL: {{GOAL}}
DOMAIN: {{DOMAIN}}
AUDIENCE: {{AUDIENCE}}
DATES: {{DATES}}
BUDGET: {{BUDGET}}
CONSTRAINTS: {{CONSTRAINTS}}
UNKNOWN_POLICY: Do not invent sources; label confidence High/Med/Low
FORMAT:
- Options compared (table if helpful)
- Pros/cons
- Risks
- Recommendation + what you must decide
- Sources list
SUCCESS_CRITERIA: {{SUCCESS_CRITERIA}}
```

## Done when
You can decide — or know exactly what fact you're missing.

## Safety
Verify prices, laws, and medical claims independently.
